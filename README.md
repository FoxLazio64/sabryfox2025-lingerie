# SabryFox2025 Lingerie

Applicazione Android React Native / Expo del marchio SabryFox2025.

Motto: Il piacere di sentirsi unica.

## Contenuto

- Boutique SabryFox2025.
- Catalogo locale dimostrativo.
- Categorie, ricerca e schede prodotto.
- Preferiti, carrello e profilo locale.
- Conservazione locale delle richieste.
- Supporto alla modalità offline.
- Identità grafica ufficiale.

## Stato del progetto

I sei prodotti iniziali sono dimostrativi.
Prezzi, giacenze, fotografie commerciali, taglie e descrizioni
definitive devono essere inseriti dal titolare.

L'indirizzo API non è ancora configurato.
Accesso online, sincronizzazione e gestione ordini sul server
richiedono un backend HTTPS separato e protetto.

I pagamenti elettronici non sono attivi.

## Compilazione Android

La compilazione APK è predisposta tramite GitHub Actions.

Aprire la scheda Actions del repository e selezionare
"Build SabryFox2025 Android APK".

Il file APK sarà disponibile negli artefatti della compilazione.
